# Cidade Nova 3D

Sua cidade. Sua casa. Sua história.

Bem-vindo ao Cidade Nova 3D, um projeto de jogo 3D multiplayer onde os jogadores poderão explorar uma cidade virtual, construir sua própria história, personalizar seus personagens e interagir com outras pessoas em tempo real.

🎮 Sobre o projeto

Cidade Nova 3D é um jogo pensado para funcionar diretamente no navegador, inclusive em celulares Android.

O objetivo é criar uma cidade virtual viva, com casas, ruas, avenidas, lojas, parques e espaços de convivência.

✨ Funcionalidades planejadas

- 🌍 Cidade 3D explorável.
- 👥 Multiplayer com jogadores em tempo real.
- 🏠 Casas próprias para os jogadores.
- 🪧 Placa com nome de usuário acima das casas.
- 👤 Perfis individuais.
- 🎨 Personalização de personagens.
- 🕹️ Controles adaptados para celular.
- 🚁 Modo câmera drone.
- 🌳 Árvores, parques, lojas e construções.
- 💾 Cadastro, login e salvamento de dados.
- 🛠️ Ferramentas exclusivas de construção para os criadores oficiais.

🕹️ Controles previstos

- Joystick: movimentar o personagem.
- Correr: aumentar a velocidade.
- Pular: saltar.
- Interagir: utilizar objetos e acessar locais.
- Drone: explorar a cidade com uma câmera livre.
